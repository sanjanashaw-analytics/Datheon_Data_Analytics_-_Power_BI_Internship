# Superstore Sales Data Analysis in Excel (Datheon Internship - Task 1)

## 📌 Project Overview
This project involves end-to-end data cleaning, exploratory data analysis, and business reporting on the Superstore Sales dataset using **Microsoft Excel**.

## 🧹 Data Cleaning & Preparation
* Identified and removed blank/missing entries to ensure data integrity.
* Removed duplicate records across the dataset.
* Formatted dates, currency, and categorical fields for accurate aggregation.

## 📈 Visual & Tabular Analysis
* **Discount vs. Profit Analysis:** Created a scatter plot to examine the correlation between discount rates and profit margins.
* **Time-Series Profit Trend:** Visualized Year-over-Year and Month-wise profit performance to track seasonal patterns.
* **Segment & Regional Breakdown:** Analyzed Sales and Profit distribution across Regions, Product Categories, and Customer Segments.
* **Business Operations Recommendations:** Outlined 5 key operational insights to optimize discounting strategies and improve profitability.

## 🛠️ Tools Used
* **Microsoft Excel** (Data Cleaning, Pivot Tables, Formulas & Charts)
